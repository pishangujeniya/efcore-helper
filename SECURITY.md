# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |

## Reporting a Vulnerability

If you discover a security vulnerability within EF Core Helper, please send create github issue.

Please include:
- A detailed description of the vulnerability.
- Steps to reproduce or proof-of-concept.
- Potential impact.
